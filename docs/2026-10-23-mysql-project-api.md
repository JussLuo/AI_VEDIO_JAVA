# MySQL 项目接口实施方案

## 目标

Java 服务连接本机 MySQL，使用 `vedio_java` 数据库并自动建表，实现项目创建和列表查询。旧项目不变。

## 配置

- 地址：`jdbc:mysql://localhost:3306/vedio_java`
- 用户名：`root`；密码通过本机 `DB_PASSWORD` 环境变量提供，不提交。
- 首次启动前创建数据库；本批已在本机创建 `vedio_java`。应用执行幂等建表脚本。
- 测试使用独立 H2 内存库，不修改本机 MySQL。

## 步骤

1. 更新 Maven 依赖及数据源配置，先写失败的接口测试。
2. 新增项目表、模型、数据访问、服务和 REST 控制器。
3. 验证创建、列表、输入校验及健康检查。
4. 运行指定 JDK 21 与 Maven 3.9.4 的测试和打包命令，审核 diff。
5. 等用户确认代码后，以中文信息提交并推送。
